## 推荐检索方式

1. 先按地区打开文件，再用 GitHub 页面搜索学校或姓名。
2. 想找具体方向时，直接打开 by-field/ 中对应的文件。
3. 申请博士时先看 by-profile/a.md，再回到个人主页核对招生状态。
